# Retail Sales BI Dashboard

## Overview
4-page interactive Power BI dashboard built on 9,994 rows 
of Superstore retail sales data.

## Tools Used
- Power BI Desktop
- DAX
- Excel / Power Query

## Data Model
Star schema with:
- Fact_Data (sales transactions)
- Dim_Customer
- Dim_Product
- Dim_Date
- Dim_Location

## Dashboard Pages
1. Executive Summary — KPIs, monthly trends, regional performance
2. Product Analysis — top products, category treemap, profit scatter plot
3. Customer Analysis — top customers, segment trends
4. Geographic Analysis — state map, city rankings

## Key Insights
- Total Sales: $2.30M across 4 years
- Copiers: highest profit margin at 37%
- Bookcases: generating losses at -3% margin
- California: strongest market by profit
- Sean Miller: top customer but generating a loss

## DAX Measures
- Total Sales
- Total Profit
- Profit Margin %
- Total Orders
- Avg Order Value
- Total Quantity
- YoY Sales Growth %
- Sales Running Total
